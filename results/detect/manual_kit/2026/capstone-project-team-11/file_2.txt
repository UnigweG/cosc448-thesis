"""Result validation and CSV import endpoints.

Endpoints
---------
POST /courses/{course_id}/exams/{exam_id}/results/preview
    Parse a CSV upload and return a full validation report (no DB writes).

POST /courses/{course_id}/exams/{exam_id}/results/confirm
    Re-parse the same CSV, validate, and commit rows only if the file has no
    blocking validation errors.

Error vs warning policy
-----------------------
Errors   — block import:
    missing_student_number      student_number field is blank
    unknown_variant             variant_code not in this exam
    not_enrolled                student not enrolled in this course
    duplicate_student           student_number appears more than once in the file
    invalid_answer              answer format doesn't match the question type
    unexpected_question_number  answer for a question that doesn't exist in the variant
    non_omr_answer              answer submitted for a written question

Warnings — non-blocking:
    missing_answer      answer field is blank
    already_imported    student already has a result (will overwrite on confirm)
"""
